# Amazon E-commerce Product Dissection

## 📌 Project Overview

This project presents a **Product Dissection of Amazon E-commerce**, focusing on real-world problems, Amazon's solutions, key features, and database design.

## 🎯 Objectives

- Analyse Amazon's core e-commerce features.
- Identify real-world problems and their solutions.
- Design a relational database schema.
- Understand entities, attributes, primary keys, foreign keys, and relationships.
- Represent the database structure using an ER Diagram.

## 🔍 Problems & Solutions

- **Limited Product Access** → Online marketplace and doorstep delivery.
- **Lack of Trust** → Reviews, ratings, seller information, and Verified Purchase reviews.
- **Product Discovery** → Search, filters, categories, and personalised recommendations.
- **Delivery Issues** → Order tracking and fast delivery services.

## ⭐ Key Features

- User Accounts
- Product Catalogue
- Shopping Cart & Checkout
- Orders & Delivery Tracking
- Search & Filters
- Personalised Shopping

## 🗄️ Database Entities

- User
- Seller
- Product
- Order
- OrderItem
- Payment
- Review
- Return

## 🔗 Key Relationships

- Users place Orders.
- Orders contain Order Items.
- Sellers list Products.
- Users review Products.
- Orders have Payments.
- Orders can generate Returns.
